# Security policy

Ghost Bot is under active development. There is no stable supported release
yet. See the [roadmap](docs/ROADMAP.md) and [security requirements](docs/SECURITY.md)
for current acceptance gates and security boundaries.

## Reporting a vulnerability

If private vulnerability reporting is enabled, use the repository's Security
tab and its private reporting option. If it is unavailable, contact the
maintainer privately; do not publish exploit details, credentials, private
logs or personal data in public issues or pull requests. A public issue may
request a private contact channel without including sensitive details.

Include the affected commit or version, environment, impact and minimal safe
reproduction steps with synthetic data. Do not test against third-party
accounts or systems without authorization.

Please allow the maintainer an opportunity to investigate and coordinate
disclosure. Response times and fixes are not guaranteed while the project
is in early development.
