# UI design system

## Visual source of truth
`design/references/workspace-dark.png` and `settings-usage-dark.png` are the user's supplied preferred UI. `grok-bot-inspiration.png` provides contextual inspiration. Match compact monochrome three-pane layout, muted text, no heavy decoration, colorful small avatars and subtle borders. Avoid importing proprietary imagery as app assets.

Desktop target 1440×900; left 240px, right 285px, center fluid; adjustable widths, collapse at narrow sizes. Top app bar 40px, chat header 60px; composer anchored below scrollable messages. Sidebar: bots/search/new bot, teams, settings. Right: live computer, routines, connected tools, account usage; label unavailable features. Chat: user bubbles dark gray, agent prose directly on canvas, compact tool progress and approval cards. Model/effort/permission bottom-left, send bottom-right. Settings: navigation left and scrollable content right; Usage section bars with percentage, source, reset window and activity chart. Light mode equivalent with contrast. Use CSS variables in design/tokens.json. Default 14px system sans, 1.5 line height, 8–12px corners, 1px borders, 8px spacing grid. Keyboard focus, semantic labels, reduced motion, adequate contrast and no color-only statuses.

## Avatar system
Original SVG shape library: Ghost, Chief, Developer, Researcher, Creative, Assistant, Automation, Observer, Writer, Security, Analyst, Personal. Two eyes are shared identity; choose shape, palette, eye style, tilt, animation. Store JSON config; use SVG and CSS rather than generated PNG per combination. States: idle blink, thinking sway, working bounce, approval pulse, sleeping narrow eyes, completed happy, error stable warning; never use animation as sole status. Custom PNG/WebP/SVG uploads must be validated and SVG sanitized/re-encoded. Use 24–40px avatars in sidebar and 80–128px in editor. Keep own identity, do not copy Grok original assets. Production component (`apps/desktop/src/components/BotAvatar.tsx`) supports accessible labels, `prefers-reduced-motion`, and manual reduced-motion toggle. Review screenshots from Phase 1B are stored in `design/reviews/phase-1b/`.
