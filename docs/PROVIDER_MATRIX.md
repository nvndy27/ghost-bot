# Provider integration matrix

Evidence reviewed 2026-11-25. A catalog, authenticated handshake, and actual model execution are separate checks.

| Route | Evidence | Status and limitations |
|---|---|---|
| OpenAI via Codex App Server | [Official App Server protocol](https://learn.chatgpt.com/docs/app-server) and generated 0.172.0 JSON schema (`codex app-server generate-json-schema`). | **Verified** on Codex CLI 0.172.0 with dedicated ChatGPT `plus` profile (`~/.config/ghost-bot/codex-profile`). Phase 0 verified `initialize`, `account/read`, `model/list`, `account/rateLimits/read`, streaming `turn/start`, `turn/interrupt`, `thread/resume`, and sandboxing. Phase 1D verified the full Electron → IPC → Daemon → Policy Broker → Codex metadata bridge (`status: available`, `planType: plus`, 10 models, 2 rate-limit windows) without inference. `full-access` remains disabled. Codex `0.172.0` schema includes `dynamicToolCall` / `mcpServer/tool/call`, but `CodexAppServerAdapter` does not implement them and native MCP remains disabled (`unsupported_native_mcp`) until policy-preserving host mediation is verified. |
| OpenClaw Gateway | [Handshake](https://docs.openclaw.ai/gateway/protocol/handshake) and [CLI](https://docs.openclaw.ai/cli/gateway) document protocol negotiation, device challenge, scoped operator access and RPCs. | **Metadata Verified / Execution Gated** on CLI `2026.11.8 (2d4ab29)` (`ws://127.0.0.1:18789` `health`, `status`, `models.list` verified; `OpenClawGatewayAdapter` implemented with loopback enforcement and deterministic protocol tests). Live execution remains gated by `RuntimePolicyBroker` until Gateway sandbox and upstream billing enforcement are verified. |
| Anthropic Claude | [Messages API](https://platform.claude.com/docs/en/api/overview), [Authentication](https://platform.claude.com/docs/en/manage-claude/authentication), [Streaming](https://platform.claude.com/docs/en/build-with-claude/streaming), and [Legal & Compliance](https://code.claude.com/docs/en/legal-and-compliance) require `x-api-key` + `anthropic-version: 2023-06-01` for third-party apps and forbid spoofing/proxying Claude.ai subscription tokens. | **Implemented / Protocol-Tested (Execution Gated)** (`AnthropicClaudeApiAdapter` implemented on `https://api.anthropic.com` with redirect rejection, `read-only` tool-free chat, SSE parsing, bounded history/tokens/duration/stream, `ghost-bot.provider` OS Secret Service namespace, `RuntimePolicyBroker.authorizeClaudeApiExecution`, and Desktop Settings + BotEditorModal UI). Subscription login remains **Blocked**; local `claude` CLI `2.1.331` assessed read-only and remains uninvoked. |
| Google Gemini | [Google transition announcement](https://github.com/google-gemini/gemini-cli/discussions/28017) ended Gemini CLI service for individual free, Pro and Ultra accounts on June 18, 2026. Enterprise and API key routes remain. [Gemini API auth](https://ai.google.dev/gemini-api/docs/api-key). | **Not Started**. API support requires separate opt-in. |
| Moonshot Kimi Code | [Official CLI release notes](https://moonshotai.github.io/kimi-code/en/release-notes/changelog.html) and docs specify `kimi login` (RFC 8628 device-code OAuth) and `kimi acp` (JSON-RPC over stdio). | **Blocked** for live verification (`kimi` CLI not installed locally). Non-blocking for Phase 1. |
| Ollama | Official loopback [version](https://docs.ollama.com/api/version), [model list](https://docs.ollama.com/api/tags), [running models](https://docs.ollama.com/api/ps), [show](https://docs.ollama.com/api/show), and [chat](https://docs.ollama.com/api/chat) endpoints. | **Implemented / Protocol-Tested (Unavailable on Host)** (`OllamaLocalAdapter` enforces loopback `http://`/`https://` without credentials, redirect rejection, cloud-model rejection, `read-only` tool-free execution, bounded `24`-turn/`32 KB` history, `2048`-token `num_predict`, `2 MB` stream limit, `120s` timeout, and `RuntimePolicyBroker.authorizeOllamaExecution` gating; Desktop Settings + BotEditorModal IPC wired). Ollama CLI and daemon (`127.0.0.1:11434`) are not installed on current host; non-blocking for Codex. |
| LM Studio, llama.cpp, OpenRouter | Deferred. | **Not Started**. |

Unknown quota stays `null`. Count observed or estimated local usage separately and label its source. Never substitute an API key account for a subscription account without user opt-in.
