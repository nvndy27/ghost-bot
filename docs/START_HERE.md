# Start here

The first real vertical slice is: user creates a bot → chooses an actually supported runtime/model/effort → sends one message → sees a streamed response → cancels or approves a real scoped action → reopens the persisted session. One provider working securely is worth more than five fake connections.

Phase 0: validate protocols and account eligibility. Phase 1: desktop shell and mock adapter. Phase 2: one verified subscription runtime + optional local model + OpenClaw integration if validated. Then add memory, tools, teams, routines, computer use and meeting assistant.

Use the supplied screenshots and prototype as design baseline. Model and quota in screenshots are example values only. Avoid using the third-party screenshot as a shipped asset.
